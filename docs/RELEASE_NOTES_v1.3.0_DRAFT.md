# 🛡️ Citadel Sentry v1.3.0 — Черновик описания релиза (DRAFT)

> **Крупное обновление движка: устранение критических ошибок запуска сидинга, оптимизация RAM и видеокарты, нативная поддержка DXGI GPU, гарантированные точки восстановления и интеграция с резервным маяком.**

---

### 🪟 Обновление для Windows

#### 🛠️ Полное исправление ошибки запуска Potato Mode (`resolutionsizex not found`)
* **Устранён вылет перед запуском**: ликвидирована ошибка `required low-resolution setting resolutionsizex not found in [/Script/Squad.SquadGameUserSettings]`, которая блокировала запуск сидинга у пользователей с разделёнными секциями настроек (когда разрешение хранится в `Engine.GameUserSettings`, а FPS — в `Squad.SquadGameUserSettings`).
* **Динамическая вставка (Injection) вместо падения**: если у игрока в файле настроек отсутствуют явные параметры разрешения или режима окна, Sentry больше не крашится, а аккуратно и бесконфликтно прописывает целевое ультра-низкое разрешение (640×480 Windowed) прямо в активную секцию игры.
* **Игнорирование мусорных конфигов `WindowsNoEditor`**: если на ПК игрока одновременно есть актуальная папка `WindowsClient` / `Windows` и старая `WindowsNoEditor` с повреждёнными или пустыми файлами, устаревшие конфиги теперь пропускаются с записью в лог без аварийной остановки миссии.

#### ⚡ Оптимизация оперативной памяти (RAM & Streaming Pools)
* **Блокировка раздувания памяти в Potato Mode**: устранены избыточные утечки, движок принудительно ограничивает кэш текстур в фоновом режиме.
* **Лимиты пула текстур и VRAM**: принудительно активированы параметры `bUncapTexturePoolSize=False`, `TextureStreamPoolSizeStorage=(Value=0)`, `r.Streaming.PoolSize=150`, `r.Streaming.LimitPoolSizeToVRAM=1` и `r.Streaming.UseFixedPoolSize=1`.
* *Примечание: точные замеры потребления RAM подлежат валидации на различных сборках ПК перед публикацией.*

#### 🎮 Нативное определение видеокарты (Windows DXGI COM API) и умные апскейлеры
* **Определение оборудования на лету**: встроен прямой опрос DirectX Graphics Infrastructure (DXGI) для точной идентификации вендора (NVIDIA, AMD, Intel) и архитектуры GPU.
* **Адаптация апскейлеров под железо**:
  * **NVIDIA RTX**: автоматическая активация DLSS в режиме `UltraPerformance` (`UpscaleMode=2`).
  * **AMD Radeon**: принудительное включение AMD FSR + `AMDFG` (AMD Frame Generation) (`UpscaleMode=1`).
  * **Intel / NVIDIA GTX**: активация AMD FSR Performance (`UpscaleMode=1`, `FSRQuality=4`).
* **Сброс тяжелого рендера в ноль**: полное отключение качества ландшафта (`sg.LandscapeQuality=0`), симуляции воды и волн (`WakeSim=0`, `OceanQuality=0`), отражений (`sg.ReflectionQuality=0`), глобального освещения (`sg.GlobalIlluminationQuality=0`) и сведение частоты обновления прицелов к минимуму (`ScopeUpdateRate=30`).

#### 🔒 Неприкосновенный базовый снимок и точки возврата (Restore Points)
* **Защита настроек игрока**: при первом запуске Sentry снимает неизменяемый эталонный снимок оригинальных настроек (`baseline/GameUserSettings.ini`).
* **Откат в один клик**: в любой момент по нажатию одной кнопки исходные настройки игрока восстанавливаются байт-в-байт.
* **Поддержка множественных снапшотов**: сохранение пользовательских профилей графики без риска потери настроек при переключениях.

#### 📡 Архитектура резервного подключения (Citadel Beacon Bot)
* **Отказоустойчивый коннект**: заложена поддержка резервного Steam-бота Citadel для мгновенного резолва актуального Steam Lobby ID серверов в обход сбоев и лимитов сторонних API (SquadBrowser 429).

---

### 🐧 Обновление для Linux (WebKit2GTK & Proton)
* **Полная синхронизация движка**: алгоритмы динамической вставки разрешения, очистка второстепенных файлов и лимиты стриминга пула памяти перенесены в бинарник для Linux.
* **Абсолютная безопасность префикса**: автоматическое определение путей в любых конфигурациях Steam Library, Proton и Flatpak.
