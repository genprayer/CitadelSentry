# Security policy

## Supported versions

Only the newest published Citadel Sentry release is intended to receive security fixes. Older artifacts are retained for rollback, not as supported versions.

## Reporting a vulnerability

Use GitHub private vulnerability reporting or contact a Citadel administrator through a private channel. Do not include access tokens, authentication payloads, private server addresses, personal data, or exploit details in a public issue.

Include the exact Sentry version, operating system, affected workflow, reproduction steps, and impact. For an unexpected sleep/shutdown action, repeated game relaunch, arbitrary process execution, authentication bypass, or token exposure, stop using the affected action until a fixed release is available.

The maintainers should acknowledge the report privately, reproduce it on test infrastructure, prepare a regression test and rollback, and coordinate disclosure after users can update. No response-time or bounty promise is made by this file.
